## 0.1.0

First release of the run surface.

- One DistSSHKit run: `setup`, `go`, `ride`, `drive`, `plan`, `size`,
  `pool`, `demo`, and `progress`.
- Users add DistSSHKit. The manual is the DistSSHKit manual.
- The user command is `julia -m DistSSHKit`. This package's `main` is the
  entry when DistSSHRun is a direct dependency.
