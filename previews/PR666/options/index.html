Environment variables

User-facing names. A parent-to-child hand-off uses DISTSSH_INTERNAL_* and is not an option. Test doubles are injected from test/ and are not read as options. An old Distributed-prefix name is an error that names the DistSSH replacement. A numeric or boolean value that does not parse is an error that names the variable. Unset uses the default. A present blank value is an error.

Precedence

Within one scope: CLI → environment → default. Per-host Distributed bind overrides come from optional bind on each [[hosts]] row in a TOML hosts file (IPv4 literal only; see Placement). drive, drive, and --dry-run validate every listed host before SSH; invalid bind values fail closed (exit 2 on the CLI, not softened by --best-effort).

Diagnostics

  • --print-config resolves settings and prints each value with its source, then exits 0 without SSH.
  • --dry-run prints placement, resolved topology and bind per host (with tunnel), and redacted worker env keys, then exits 0 without SSH.
