CLI conventions

DistSSHRun and julia -m DistSSHKit follow the same exit conventions as clap, especially Command::arg_required_else_help:

SituationOutput streamExit code
No arguments on a command that needs operands or flags (go, drive, up, setup, or the top-level driver with no subcommand)Full --help text on stderr2
Explicit --help / -hSame help text on stdout0
Usage error (unknown flag, missing operand, bad combination)Error and a short hint on stderr2
Runtime failure (SSH error, job failure, missing file, …)Diagnostics on stderr (command-specific)1 (unless documented below)
Ctrl-C in the foreground—130
Broken pipe (EPIPE) while writing—141
Opt-in worker heartbeat: controller silent past deadline—75

Display commands whose bare invocation is already meaningful keep their defaults: hostinfo, pool, setup requirements, progress (uses the current directory when no path is given), and similar.

doctor will follow the same table in a separate change.
