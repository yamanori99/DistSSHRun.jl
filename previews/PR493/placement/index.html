Placement and host lists

Worker placement uses machine tokens shared by --hosts, hosts files, and --machine-file:

N*[user@]host[:port]

Examples (always quote --hosts so the shell does not glob-expand *):

julia -m DistSSHKit drive --local-workers 2 --hosts '4*user@lab:2222,2*[::1]' script.jl
  • A bare host means one worker (host ≡ 1*host).
  • : after the host is the SSH port only (as in Julia's machine file).
  • IPv6 literals must be bracketed (2*[fe80::1]:2222).

Local capacity is not a placement token. drive / ride: --local-workers N (DISTSSH_LOCAL_WORKERS only). go: --local-slots N. With no hosts and no --local-slots, go still runs one local slot and prints local: <hostname>, 1 slot (no hosts given); --local-slots 0 with no hosts is a usage error.

Host list sources

Exactly one source applies:

  • --hosts CSV
  • --hosts-file (plain lines or TOML with [[hosts]] and required name)
  • --machine-file (one token per line)

DISTSSH_HOSTS / DISTSSH_HOSTS_FILE apply only when the CLI does not set a host list (they are never merged with --hosts). Two explicit CLI sources are an error. When a job resolves hosts, it prints hosts (from …): …; if DISTSSH_HOSTS is set but overridden by CLI, it also prints DISTSSH_HOSTS is set but overridden by ….
