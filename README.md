# DistSSHRun

One DistSSHKit run on shared machines over SSH: `go`, `drive`, `ride`, `setup`, `plan`, `size`, and `pool`.

Users add [DistSSHKit](https://github.com/yamanori99/DistSSHKit.jl). The manual is the Kit manual: <https://yamanori99.github.io/DistSSHKit.jl/stable/>.

This repository is the run surface. Base-shaped code still lives here. It is not on Kit's main yet.
