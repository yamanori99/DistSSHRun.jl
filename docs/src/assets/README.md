# Docs assets

There is no package mark. `custom.css` is the Documenter theme tweak.
`social/social-preview-static.svg` is a text-only card (no icon, no GIF).
`social/social-preview-static.png` is the 1280×640 raster of that card.
`pkgeval.svg` is written by the PkgEval badge workflow once Nanosoldier has this package.

Upload `social/social-preview-static.png` under GitHub → Settings →
General → Social preview. Pushing the file does not change that image.
