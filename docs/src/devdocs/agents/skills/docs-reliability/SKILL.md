# Docs reliability

Follow the setup and run steps the task cites in `README.md` or `CONTRIBUTING.md`. Do not read either file end to end. Report each drifted step as stale, incomplete, or misleading, and name the command that showed it.

Name the OS that step needs. A failure on native Windows is not a docs defect.

Do not assign a score. Do not start a second agent.
