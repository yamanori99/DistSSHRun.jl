category: breaking

- Kit and `julia -m DistSSHRun` CLI entry points follow [clap](https://docs.rs/clap) [`arg_required_else_help`](https://docs.rs/clap/latest/clap/struct.Arg.html#method.required): a command that needs operands or flags, invoked with no arguments, prints its full `--help` page on **stderr** and exits **2** (not **0** or **1**). Explicit `--help` / `-h` still prints on **stdout** and exits **0**. Usage errors (unknown flags, missing operands, bad combinations) exit **2**; runtime failures keep their own non-zero codes (typically **1**, Ctrl-C **130**, EPIPE **141**, worker heartbeat **75** when enabled). `hostinfo`, `pool`, `setup requirements`, and similar display commands keep a meaningful bare invocation. `doctor` will align in a separate change.
