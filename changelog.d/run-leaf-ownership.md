category: breaking

- Ship writes a minimal `run.toml` under each remote `runs/<run_id>/` with `schema`, `writer`, and `kind = "ship"` only. `setup --delete` refuses a Ship leaf whose `run.toml` is present but not DistSSHRun-owned, including when that path contains a newline, the entry is a symlink or other non-regular file, or the text has an unclosed quote or bracket. The check is the deploy root's `runs/<run_id>/run.toml`, including when the confirmed delete path is a git-work-tree ancestor of that deploy root. `setup --prune` applies the same check to `.distsshkit` candidates (including nested stamps under a candidate). Local prune refuses a FIFO, directory, symlink, or other non-regular `run.toml` without opening it. A missing file (older trees) still uses structural checks only. Remote `setup --prune` also refuses when a path to `.distsshkit` contains a newline, so that line-oriented walk cannot prune a prefix of the path.
