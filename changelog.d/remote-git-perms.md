category: breaking

- Every remote git command, including `setup --clone`, passes `--no-optional-locks` and ephemeral `-c` for `advice.detachedHead=false`, `submodule.recurse=false`, `gc.auto=0`, and `core.autocrlf=false`. `safe.directory` is still not set. A remote project directory that is group-writable or world-writable is refused before checkout. The check follows a symlink and fails closed when `ls` does not print a directory mode. `setup --clone` keeps the remote umask and also masks group and other write. It refuses a group- or world-writable destination before cloning. A missing destination is created with mode `755`, group and other write are cleared again, and that mode is checked before clone because a default ACL can override `mkdir -m`. A missing directory is not created by the checkout check.
