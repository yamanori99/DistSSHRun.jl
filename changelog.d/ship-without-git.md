category: breaking

- `--ship-tree` no longer needs a git work tree and does not run git. The send list walks the ship root and applies each directory's `.gitignore` (case-sensitive; `core.ignorecase` is not used), including inside a nested `.git`. `.git/info/exclude`, `core.excludesFile`, and a `.gitignore` above the ship root are not used. `ShipTreeResult.tree_matches_head` is `nothing` because the tar is not compared to a git tree. Schema 1 `run.toml` does not carry that field. A gitignored `Project.toml`, `JuliaProject.toml`, `Manifest.toml`, or `JuliaManifest.toml` is left out with one warning, and the rest of the tree still ships. A gitignored `LocalPreferences.toml` is not added back; add `!LocalPreferences.toml` to ship it. Declared inputs stay out. `rsync_send_list`, `--clone`, `--sync`, and `--pull` stay on git.
