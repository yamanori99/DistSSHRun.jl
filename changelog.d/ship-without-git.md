category: breaking

- `--ship-tree` no longer needs a git work tree. The send list is a walk of the project that applies each directory's `.gitignore` (case-sensitive; `core.ignorecase` is not used). `.git/info/exclude`, `core.excludesFile`, and a `.gitignore` above the project are not used. Tracked files that match `.gitignore` are not sent. Path sources follow the same walk. The environment root counts as shipped. A `[sources]` or Manifest `path` omitted by `.gitignore`, a Manifest or path-source symlink hop omitted, or the selected `Project.toml` / `JuliaProject.toml` (including under a path source) omitted, is refused. Manifest deps without `path` are not checked this way. Format 1 top-level package tables with `path` are included. A Manifest `path` of the environment root is the clone itself. The ignored file is not forced into the tar. Preference files next to a shipped `Project.toml` or `JuliaProject.toml` are included. Matching is GitIgnore 0.1.1, loaded when the send list is built so workers can precompile DistSSHRun without that dep. As of 2026-11-02, treat send-list mismatches as possible matcher bugs. `rsync_send_list` is still the git list.
