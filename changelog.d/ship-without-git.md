category: breaking

- `--ship-tree` no longer needs a git work tree and does not run git. The send list walks the project directory that was passed, not the workspace Manifest directory, and applies each `.gitignore` there and below (case-sensitive; `core.ignorecase` is not used), including inside a nested `.git`. `.git/info/exclude`, `core.excludesFile`, and a `.gitignore` above that directory are not used. A Manifest or path dependency outside that directory is left out with a warning. An absolute `[sources]` path is still an error. `ShipTreeResult.tree_matches_head` is `nothing` because the tar is not compared to a git tree. Schema 1 `run.toml` does not carry that field. A gitignored `Project.toml`, `JuliaProject.toml`, `Manifest.toml`, or `JuliaManifest.toml` is left out with one warning, and the rest of the tree still ships. A gitignored `LocalPreferences.toml` is not added back; add `!LocalPreferences.toml` to ship it. Declared inputs stay out. `rsync_send_list`, `--clone`, `--sync`, and `--pull` stay on git. `go` still resolves `env_dir` from the Manifest.
