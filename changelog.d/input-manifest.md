category: changed

- A declared input with hashing on is recorded as `sha256-manifest-v1` under `DISTSSHKIT_RUN_DIR/inputs/`. The file name is a sanitized `<name>--<host>` stem; characters outside `A-Za-z0-9._@-` become `_`, and a changed stem gets an eight-hex SHA-256 suffix. Each line is `hex *path`. A regular file contributes the SHA-256 of its bytes. A symlink contributes the SHA-256 of its link text and is not followed, so `sha256sum -c` does not check that line. A link target with a tab or newline is refused. A path with a backslash is refused. `check_input_manifest(manifest, root)` checks both. Paths are relative to the declared root, NFC, separated by `/`, and sorted in byte order. A file input is one line whose path is that file's basename. `run.toml` `inputs` lists `name`, `path`, `host`, `algorithm`, `content_hash`, `files`, `bytes`, `verification`, and `hashed_at`. `hash = false` sets `verification` to `stat`, omits `content_hash`, records `newest_mtime` and `stat_digest`, and does not write a `.manifest`. Ship prints `hashed <name>: <size> in <seconds> s`. Content hashing also prints progress and a remaining-time estimate. `ship-tree` refuses a repeated host.
