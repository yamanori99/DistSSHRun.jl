- A declared input with hashing on is recorded as `sha256-manifest-v1` under `DISTSSHKIT_RUN_DIR/inputs/<name>--<host>.manifest`, Each line is `hex *path`. A regular file contributes the SHA-256 of its bytes. A symlink contributes the SHA-256 of its link text and is not followed, so `sha256sum -c` does not check that line. `check_input_manifest(manifest, root)` checks both. Paths are relative to the declared root, NFC, separated by `/`, and sorted in byte order. A file input is one line whose path is that file's basename. `run.toml` `inputs` lists `name`, `path`, `host`, `algorithm`, `content_hash`, `files`, `bytes`, `verification`, and `hashed_at`. `hash = false` sets `verification` to `stat`, omits `content_hash`, and records `newest_mtime` and `stat_digest`. Ship prints `hashed <name>: <size> in <seconds> s`. Content hashing also prints progress and a remaining-time estimate. `ship-tree` refuses a repeated host.
