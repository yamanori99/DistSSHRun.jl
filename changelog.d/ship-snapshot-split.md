- `snapshot(local_root)` builds the ship tar in a temporary directory and records `content_tree_hash`. The caller deletes that directory. `ship(snapshot, hosts, remote_root; confirm=false, record=true)` sends that tar, does not pack again, and does not delete it. It re-hashes the tar immediately before sending and throws `ArgumentError` when the hash differs. Depot-preference refusal runs in `ship`. `record=false` does not keep the ship for controller `run.toml` in this process. `ship_project_to_hosts!` still confirms and deletes its temporary directory. `result_content_tree_hash` and `result_remote_run_id` read those values from a `:ship_tree` `SyncResult` and from `ShipTreeResult`. Other `SyncResult` values return `nothing`. These names are public and are not exported. `SyncResult` field order is unchanged and the fields are not API.
