category: breaking

- Detached `execute!` starts in the project directory, passes `--threads=1` and `--history-file=no`, and keeps an allowlist of environment variables. `dir`, `threads`, `env_allow`, and `env` override that. Restore the previous working directory, thread flag, and environment copy with `dir=pwd()`, `threads=:unset`, and `env_allow=:all`. That still drops `JULIA_LOAD_PATH`, the CLI include guards, names containing `COOKIE`, names containing `SECRET`, `PASSWORD`, `PASSWD`, `TOKEN`, `API_KEY`, `APIKEY`, `ACCESS_KEY`, `PRIVATE_KEY`, or `CREDENTIAL`, and the proxy variables `http_proxy`, `https_proxy`, `all_proxy`, `no_proxy`, and their uppercase forms when the value contains userinfo. Pass a denylisted name or such a proxy value with `env`, or name it in an `env_allow` list. The list keeps the baseline and those names, and does not copy the rest of the parent environment. `JULIA_LOAD_PATH`, the CLI include guards, and names containing `COOKIE` cannot be passed that way.
- Local go slots and local drive workers inherit that environment, and their thread count follows the child. `SSH_AUTH_SOCK` is on the allowlist, so local workers inherit the agent socket. SSH workers are unchanged. A `drive --isolated` grandchild inherits the filtered environment.
- `run.toml` gains `[launch]` (`threads`, `dir`, `dropped`) and stays schema 1. Detached `execute!` logs how many names were dropped. The names are in `detached_launch`, `[launch]`, and the debug log.
- In-process `execute!` and `julia -m DistSSHKit` are unchanged.
